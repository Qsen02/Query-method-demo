# Summary
This is demo for new http method QUERY reaslised into simple REST API.
# Technologies
- Front-end: React
- Back-end: Express with MongoDB
# Instructions:
- Server: You need to start the server with command `npm start`.
- Client: You need to start the client with command `npm run dev`
- Data: You have folder `data` which includes test data. You can import these data in MongoDB compass.
# Endpoints
- /notes (GET) - Get all notes in database
- /notes (POST) - Create new note
- /notes/search (QUERY) - Search notes. Here is the endpoint with this new method.
